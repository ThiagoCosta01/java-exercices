# ☕ Java Exercises

A repository dedicated to my **Java** learning journey, following a structured roadmap that covers everything from language fundamentals to advanced topics used in professional backend development.

The goal of this project is to strengthen my knowledge through **hands-on exercises**, **small projects**, and **best practices**, while maintaining a public record of my progress.

---

# 🎯 Objectives

- Learn Java through a structured roadmap.
- Reinforce concepts with practical exercises.
- Build small projects for each learning module.
- Develop a solid foundation before moving to frameworks like Spring Boot.
- Build a public technical portfolio.

---

# 📚 Repository Organization

Each learning module has its own branch containing:

- study notes and explanations;
- solved exercises;
- small projects;
- commits documenting the learning process.
