# ☕ Java Exercises

Repositório dedicado aos meus estudos da linguagem **Java**, organizado em uma trilha de aprendizado progressiva, desde os fundamentos até tópicos avançados utilizados no desenvolvimento profissional de aplicações backend.

O objetivo deste projeto é consolidar conhecimento através de **exercícios**, **pequenos projetos** e **boas práticas**, criando também um histórico público da minha evolução.

---

# 🎯 Objetivos

- Aprender Java de forma estruturada.
- Consolidar conceitos através de exercícios práticos.
- Criar pequenos projetos para cada módulo.
- Desenvolver uma base sólida antes de utilizar frameworks como Spring Boot.
- Construir um portfólio técnico público.

---

# 📚 Organização

Cada etapa do estudo possui sua própria branch contendo:

- explicações e anotações;
- exercícios resolvidos;
- pequenos projetos;
- commits documentando a evolução.
